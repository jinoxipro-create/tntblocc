# Bloc TNT

Mod Fabric pour Minecraft 1.21.11 : chaque bloc posé explose comme une TNT au bout de 15 secondes.
Un timer décroissant est affiché au-dessus du bloc.

## Compiler le jar

Pousse ce dossier sur GitHub : l'onglet **Actions** compile automatiquement le mod.
Le jar est téléchargeable dans l'artefact `bloctnt-jar` de l'exécution.
